# Nova Salud - Sistema de Gestión

Nova Salud es una aplicación web diseñada para gestionar inventario, ventas y atención al cliente en una farmacia. Este sistema centralizado y automatizado mejora la eficiencia operativa y la experiencia del cliente.

## Características

- Gestión de inventario con actualizaciones en tiempo real.
- Alertas automáticas para reabastecimiento de productos.
- Registro de ventas con interfaz intuitiva.
- Base de datos para clientes y productos.
- Diseño moderno y responsivo utilizando Tailwind CSS.

## Tecnologías

- React + TypeScript
- Tailwind CSS
- Vite
- MySQL
